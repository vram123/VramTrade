# What we worked on today

## 1. CLAUDE.md
Created the initial `CLAUDE.md` for the repo (commands, architecture) and kept it updated as the
codebase changed throughout the session.

## 2. Accounts & settings
- Added a small Django + Django REST Framework backend (`backend/`) that handles only account
  register/login/logout/delete via token auth. Portfolio, watchlist, and theme all stay in the
  browser's `localStorage` — the backend never touches trading data.
- Replaced the header's "Reset portfolio" button with a Settings page covering: account
  login/register/delete, an appearance toggle (system/light/dark), and "Reset portfolio" (now
  limited to once every 7 days).

## 3. Navigation redesign
- The header button + footer-links approach evolved into a persistent left-hand Sidebar
  (Dashboard / Market News / Trading Guides / Settings) with dedicated pages for News and Guides.

## 4. Trading Guides course
Rebuilt from a short static reference into a full course:
- 8 chapters × 4 topics, ~4 hours of real content total.
- Restructured into an IBM-style gated learning path: each chapter is read as its own full page,
  followed by a 5-question quiz. 70% (4/5) is required to unlock the next section.
- Passing all 8 sections mints a certificate (aggregate score out of 40), with print/PDF support.
- Added an "Outside resources" section (SEC, FINRA, Investopedia, Khan Academy, FRED, and a few
  books) on the course overview page.

## 5. Mobile-first CSS
Converted the stylesheet's responsive breakpoints from desktop-first (`max-width` overrides) to
mobile-first (base mobile styles, `min-width` enhancements for larger screens), wrapped the
Holdings/Trade History tables in a horizontal-scroll container, and widened the shared page
container used by Settings/News/Guides from 520px to 760px.

Everything was verified with a headless-browser pass (registration/login flow, dark mode, the full
8-section course path including a deliberate fail-and-retry, and mobile viewport rendering) plus
`tsc -b`, `oxlint`, and `npm run build`.
